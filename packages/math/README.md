# @policy/math

TypeScript port of the Polis clustering/bridging math, validated by a
**differential test suite**: every stage must reproduce the outputs of
[red-dwarf](https://github.com/polis-community/red-dwarf) (the reference
Python implementation) on real conversations from
[compdemocracy/openData](https://github.com/compdemocracy/openData),
permanently, in CI.

Reference outputs live in `test/fixtures/*/reference.json`, generated by
`tools/reference/generate.py` (pinned red-dwarf version, `random_state=42`).
Regenerate only when fixtures or the pinned reference version change.

## Ported (differential suite: 48 tests, all stages)

- Vote loading (Polis export conventions: 1 agree / -1 disagree / 0 pass;
  latest vote per pair wins) and raw matrix construction
- Moderation zero-out and the ≥7-votes clusterable-participant filter
- **PCA stage**: mean imputation → 2-component PCA → sparsity-aware scaling
  (`√(n_statements / n_votes)`), participant and statement projections
  — matches red-dwarf to 1e-6 (components/projections) and 1e-9 (means)
- **Clustering**: PolisKMeans with the deterministic "polis" init (first k
  sorted-unique points), sklearn-semantics Lloyd, silhouette k-selection
  (2..5) — cluster labels match red-dwarf **exactly**
- **Statistics**: one/two-proportion z-tests with Polis smoothing, per-group
  comment stats, group-aware consensus, representative-statement (repness)
  and overall consensus selection — all to 1e-9 including selection order

## Our layer (not a port): diagnosis

`src/diagnosis.ts` computes the concept paper's conflict diagnoses from vote
stats + the argument graph: `bridge_of_reasons`, `bridge_of_results` (the P17
pseudo-consensus warning), consultation-level `value_conflict` and
`pseudo_fact_fight`. Unit-tested against constructed ground-truth matrices.
**Thresholds are provisional v0 defaults** (`DEFAULT_THRESHOLDS`, documented
in-code) pending review and validation against real consultations.

## Determinism

No RNG in the PCA stage; eigenvector signs are normalized (largest-magnitude
entry positive). Clustering will use a seeded deterministic PRNG. Same inputs →
bit-identical outputs, by design — this is a trust property of the platform,
not an implementation detail.
